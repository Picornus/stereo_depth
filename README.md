## О проекте

Реализован полный классический пайплайн стереозрения — от стереопары
изображений до трёхмерного облака точек и карты глубины. Проект
демонстрирует применение фундаментальных методов компьютерного зрения:
фильтрации, стереосопоставления, постобработки и геометрических
преобразований.

**Ключевая идея:** глубина точки сцены обратно пропорциональна
диспаратности — разнице горизонтальных координат её проекций на левом
и правом изображениях:

$$
Z = \frac{f \cdot B}{d}
$$

где `f` — фокусное расстояние, `B` — база между камерами, `d` — диспаратность.

**Почему классические методы, а не нейросети:**
- интерпретируемость каждого этапа;
- работа на CPU без обучения;
- соответствие программе курса;
- нейросети оставлены как направление развития.

## Методы

### Пайплайн

1. **Предобработка** — grayscale, Gaussian blur (3×3), опционально CLAHE.
2. **Стереосопоставление** — `cv2.StereoSGBM_create` (Semi-Global Block Matching).
3. **Постобработка** — Left-Right Consistency + WLS-фильтр или медиана 5×5.
4. **Перевод в глубину** — `Z = f·B/d`.
5. **3D-реконструкция** — `cv2.reprojectImageTo3D` с Q-матрицей.
6. **Визуализация** — палитры TURBO/JET, гистограммы, облако точек.

### Используемые техники CV

| Техника | Применение |
|---|---|
| Фильтрация | Gaussian blur (предобработка), медиана (постобработка) |
| Пороговая сегментация | отсечение невалидных пикселей `disp > 1.0` |
| Стереосопоставление | BM, SGBM |
| Регуляризация | штрафы `P1`, `P2` за разрывы диспаратности |
| LRC | left-right consistency для фильтрации ошибок |
| Цветовые карты | TURBO, JET для визуализации |
| Геометрия | reprojectImageTo3D, Q-матрица |

### Параметры SGBM для сцены Teddy

```python
cv2.StereoSGBM_create(
    minDisparity=0,
    numDisparities=64,
    blockSize=5,
    P1=8 * 1 * 5**2,
    P2=32 * 1 * 5**2,
    disp12MaxDiff=1,
    uniquenessRatio=10,
    speckleWindowSize=100,
    speckleRange=32,
    preFilterCap=63,
    mode=cv2.STEREO_SGBM_MODE_SGBM_3WAY,
